# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues.**

Instead, use one of these private channels:

1. **GitHub private vulnerability reporting** (preferred): [Report a vulnerability](https://github.com/appdna-ai-inc/appdna-sdk-react-native/security/advisories/new)
2. **Email**: [support@appdna.ai](mailto:support@appdna.ai) with the subject line `SECURITY: <short summary>`

Please include the SDK version, a description of the issue, and reproduction steps if possible. Redact any API keys, tokens, or end-user data from logs and examples.

We will acknowledge your report within 3 business days, keep you informed of progress, and credit you in the fix release notes if you'd like.

## Supported versions

Security fixes land in the latest released version. If you are on an older version, please update to the latest release before reporting, in case the issue is already fixed.

## Scope

This policy covers the AppDNA SDK in this repository. For issues with the AppDNA platform, console, or APIs, email [support@appdna.ai](mailto:support@appdna.ai).
